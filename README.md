# 📇 부수 한 걸음 (Hanja Radical Learner)

중흥고등학교 환이 친구들이 한문 부수 수행평가를 완벽하게 대비할 수 있도록 돕는 **모바일 최적화 웹 애플리케이션**입니다. 
한자 부수, 결합 원리, 사자성어를 직관적이고 재미있게 학습할 수 있습니다.

## 🌟 주요 기능
* **플래시카드 학습:** 사람, 동물, 자연 등 갈래별 부수 뜻/음 및 변형 모양 학습
* **일일 퀴즈 세션 (SRS 기반):** 망각 곡선을 고려하여 틀린 문제는 자주, 맞은 문제는 나중에 복습하도록 설계된 알고리즘
* **실전 모의고사:** 실제 수행평가 비율에 맞춘 25문항 랜덤 출제 및 자동 채점
* **쓰기 연습 모드:** 주관식 평가를 대비하여 직접 종이에 써보고 확인하는 기능
* **학습 기록 (Streak):** 잔디 심기(달력) UI를 통한 연속 학습일 및 경험치(XP) 트래킹
* **오프라인 연동:** LocalStorage를 활용하여 별도의 DB나 로그인 없이 개인의 학습 데이터를 브라우저에 안전하게 저장

## 🛠 기술 스택
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (No Frameworks)
* **Design:** CSS Variables 기반의 전통적인 색감(한지, 먹, 인주, 청자색) 적용, 모바일 우선(Mobile-first) 반응형 UI
* **Data:** LocalStorage API

## 💡 개발 포인트
* 라이브러리나 프레임워크에 의존하지 않고 **단일 파일(Single File)** 구조로 모든 로직과 뷰를 구현했습니다.
* 터치 디바이스에 최적화된 Swipe 및 Tap 인터랙션을 구현했습니다.
* CSS Animation과 Keyframes를 활용해 정답/오답 및 도장(인주) 애니메이션을 시각적으로 구현했습니다.
